# Jojo Tournament Mod

Required mod to play in the Jojo Tournament.

**[Website](https://josephcarmichael.github.io/JOJOone/)** ·
**[Download the latest pack](https://github.com/JosephCarmichael/JOJOone/releases/latest/download/JOJOone-friend-pack.zip)**

Install: CurseForge → **Create Custom Profile** → **Import** → pick the zip. Importing a newer
pack makes a new profile; delete the old one afterwards.

This repository holds only the website and the releases. A fan project, not affiliated with
Mojang or with the JoJo's Bizarre Adventure rights holders. The map is Desolate Desert by
Quillmark (MIT NON-AI licence, inside jojo-mappack); Stands come from JCraft; the background
footage was filmed in game with Complementary Shaders. The music is *DesertComplete* by
Joseph Carmichael, who created it in BeepBox (played here with CC0 / public-domain instrument
samples: VSCO-2 Community Edition and the Versilian Community Sample Library by Versilian
Studios; oud by Freesound user hammondman).
